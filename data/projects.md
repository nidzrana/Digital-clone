# My other projects in detail

## MindBridge: RAG-based student wellbeing chatbot (2026)
MindBridge is a chatbot I built to support homesick students. It is a Retrieval-Augmented Generation (RAG) system, built with Python, FAISS, Flan-T5, Groq/Llama and Gradio.

I benchmarked a Flan-T5 model against a Groq Llama RAG pipeline to see which gave better, safer answers. I also built a 5-level stress classification system that ranges from mild to severe stress, and it reached a 98% safe-response accuracy rate.

For evaluation I created an 80-question benchmark dataset spread over 7 files, plus an HTML-based evaluation frontend so I can compare the two models side by side.

The hardest part of MindBridge was the API configuration.

## Campus Marketplace: full-stack mobile app (2026)
Campus Marketplace is a 4-role, multi-campus marketplace app built with React Native, Expo, Supabase and Node.js. I built the Campus Admin portal end to end, which is 23 of the 54 screens, going from Figma designs all the way to production code.

I implemented a shared design system and theming architecture that is reused across all the admin screens, which made the UI more consistent and development faster. I integrated Supabase Auth, Database and Storage, and delivered domain-based campus assignment, geofencing and role-specific access control. The scope is comparable to consumer marketplace apps like Daraz.

It was challenging because it was my first app, and it pushed me to get out of my comfort zone.

## Kharchay: expense tracker and HCI case study (2026)
Kharchay is an interactive expense-tracking mobile app built with React Native, Expo and Figma. I designed it to be user-friendly and evaluated it against Nielsen's usability heuristics as part of an HCI case study.

## Byzantine-resilient federated learning for IoT intrusion detection (2026)
This is my research paper, about the cyber attack chain. It covers 4 attacks: reconnaissance, man-in-the-middle, replay and spoofing. It addresses multi-stage IoT attack kill chains using Byzantine-resilient federated learning for intrusion detection. We presented it as a poster at an international conference, ICARMP 2026.
